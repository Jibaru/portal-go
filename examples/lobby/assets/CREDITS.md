# Asset credits

## Character sprites

`antifarea_charsets.png` (source) and `characters.png` (extracted, normalized):

- **"Twelve 16x18 RPG sprites, plus base"** by **Antifarea (Charles Gabriel)**,
  commissioned by OpenGameArt.org.
- Source: https://opengameart.org/content/twelve-16x18-rpg-sprites-plus-base
- License: **CC-BY 3.0** — https://creativecommons.org/licenses/by/3.0/
- `characters.png` is a mechanical re-layout of the original (frames carved
  onto a transparent 12×(48×72) grid; rows per character: down, left, right,
  up; 3 walk frames each). No artistic changes.

To use your own character sheet locally, pass `-sprites path/to/sheet.png`
with the same layout: N characters side by side, each 48 px wide × 72 px tall
(3 frames of 16×18 per direction row; row order down, left, right, up).
